# Work from the editor

Select code and use the **lightbulb** (`Ctrl+.` / `Cmd+.`) for quick Codeep
actions:

- **Explain this code**
- **Improve / refactor this code**
- **Add tests for this code**
- **Add doc comment**

When there's an error or warning on the line, the lightbulb also offers
**Fix this problem** — it sends the diagnostic plus the code to Codeep.

Other handy shortcuts:

- `Ctrl+Shift+X` — send the selection to chat
- `Ctrl+Shift+I` — inline edit the selection in place
- `Ctrl+Shift+A` — attach the active file as context

All of these are also on the editor right-click menu.
