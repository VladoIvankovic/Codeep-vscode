# Open the chat

Open the **Codeep** view from the Activity Bar, or press `Ctrl+Shift+C`
(`Cmd+Shift+C` on macOS).

The status bar shows the connection state and the active model
(`$(circuit-board) Codeep · <model>`). Click it any time to switch models.

Ask anything — Codeep can read your workspace, propose edits (shown as a diff
you approve), run commands, and use MCP tools and skill bundles.
